Cómo escribir la tuya

  1. Empieza con un recuerdo de las dos. Un viaje, una tontería o una noche de plática.
  2. Dile una cualidad suya con un ejemplo de cuándo la viste.
  3. Agradécele algo concreto.
  4. Cierra con un plan para verse pronto.

Si es tu amiga de toda la vida, mira las cartas para mi mejor amiga.

Preguntas frecuentes

¿Qué le escribo a una amiga en una carta?

Un recuerdo de las dos, una cualidad suya con ejemplo y un gracias concreto.

¿Puedo usar estas cartas tal cual?

Sí. Son para copiar, cambiar y mandar.

¿La postal se guarda en algún lado?

No. Se arma en tu teléfono y sólo sale si tú la mandas.
